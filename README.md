# ❤️ AI Heart Disease Predictor

## 🚀 Project Overview
This project delivers a complete AI-powered heart disease risk prediction system. It combines a machine learning model trained on the UCI Heart Disease Dataset 📊 with a responsive web application 🌐 and a Python backend 🐍 for real-time predictions.

## ✨ Features
- 💡 Real-time heart disease risk prediction using 13 clinical parameters
- 🌍 Responsive, mobile-friendly web application interface
- 🧠 Logistic Regression ML model with 62.30% accuracy
- 📈 Probability confidence scores for predictions
- 🛠️ Comprehensive input validation and error handling
- 📚 Fully modular Python implementation for easy integration
- 🔒 Fully offline capable with no external dependencies

## 🛠️ Installation

### Requirements
- Python 3.7+
- Packages: pandas, numpy, scikit-learn


### Setup

1. Clone or download this repository
2. Open `Web Application/index.html` in any modern browser
3. Use `Python Implementation/heart_disease_prediction_system.py` for backend predictions

## 🎯 Usage

### Web App
1. Open `Web Application/index.html`
2. Fill all 13 patient health parameters
3. Click **Predict Risk** button
4. View risk and confidence results
5. Use **Reset Form** to try new data


## 📚 Dataset
Trained on the **UCI Heart Disease Dataset** (Cleveland database) with 303 patient records, including 13 clinical features and balanced target classes.

## 📊 Model Performance
- Best Model: Logistic Regression
- Test Accuracy: 62.30%
- Precision: 62.96%
- Recall: 56.67%
- F1 Score: 59.65%
