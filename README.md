# CardioPredictAI 🩺

An AI-powered web application designed to predict cardiovascular disease risk using Machine Learning. This project features a modern React frontend and a high-performance FastAPI backend.

## 🚀 Features
- **Accurate Predictions:** Uses trained Machine Learning models to assess heart health.
- **Modern UI:** Built with React, TypeScript, and Tailwind CSS for a responsive experience.
- **Fast API:** Powered by FastAPI for quick data processing and model inference.

## 📁 Project Structure
- **/backend**: Contains the Python FastAPI server and the ML model logic.
- **/src**: Contains the React + TypeScript frontend source code.
- **/assets**: Project images and documentation resources.

## 🛠️ Tech Stack
- **Frontend:** React.js, TypeScript, Tailwind CSS, Vite.
- **Backend:** Python, FastAPI, Uvicorn.
- **Machine Learning:** Scikit-learn, Pandas, NumPy.
